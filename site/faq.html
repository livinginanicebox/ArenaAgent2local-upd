01

How it works

Is Arena Local a separate chat app or Arena clone?

No. You continue prompting on Arena.ai. Arena Local is a desktop companion that receives authenticated requests from Arena's Bash tool and applies local permission controls.

Does Arena Local upload my entire workspace?

No. File contents are returned when requested through read/search actions. The app does not send every file automatically. Only request material you intend to share with the Arena.ai session.

Why does it use ngrok?

The desktop task API listens on loopback and is not directly reachable by Arena.ai. ngrok provides a temporary HTTPS path to that API. The desktop UI itself is not tunneled.

Does Arena need my ngrok authtoken?

No. The authtoken is used by the desktop app to start the tunnel and is separate from the short-lived pairing key in the copied setup prompt. Never paste the ngrok authtoken into Arena.

02

Permissions & safety

What is the default permission mode?

Ask before changes. Reads are available; writes and shell commands pause in the local approval queue until you approve or deny them. Read only blocks mutations. No approval — VERY DANGEROUS runs mutations immediately.

Are terminal commands restricted to my selected folder?

No. Commands run with your normal OS-user permissions and can access files outside the workspace. The workspace path checks protect file tools, not the shell. Review every command; the approval gate is not an OS sandbox.

What happens when I stop the link or rotate the key?

The tunnel URL or current bearer key is revoked, and pending approvals are cancelled. An action that was already approved and is running is not undone or interrupted.

What happens in No approval mode?

File writes and shell commands execute without a local per-action prompt. It is labeled VERY DANGEROUS, requires two native confirmations, and is temporary. Use Ask mode unless you understand the risks.

Are protected filenames completely invisible?

Not always. A parent-folder listing may show the name of a protected file or symlink with a LOCKED marker. File tools will not open or follow it. Do not use shell commands to bypass these protections.

03

Setup & downloads

Why does Windows warn that the installer is unrecognized?

The installer is not code-signed, so Windows may show its standard SmartScreen warning. Download it only from the official GitHub release linked on this site, and check the published SHA-256 sidecar when available.

Where is the latest installer?

Use the download page. It resolves the latest published GitHub Release and shows whether a checksum sidecar is available. The release assets are hosted on GitHub.

My connection will not start. What should I check?

Confirm the ngrok authtoken was saved, that the computer has an internet connection, and that Arena Local shows the current setup state. Try stopping and starting the link again; if it still fails, copy the exact error text (without any secrets) into a GitHub issue.

Can I change the workspace while connected?

No. Stop the remote link first, then choose a different folder. Changing workspaces clears session approvals and returns no-approval mode to Ask.

Where should I report a bug?

Open a GitHub issue with the app version, operating system, steps to reproduce, and relevant logs. Remove the tunnel URL, bearer key, ngrok token, workspace content, and personal data first.
