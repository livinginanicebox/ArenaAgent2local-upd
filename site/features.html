WHAT THE BRIDGE DOES

A narrow bridge.
A lot more control.

Arena Local connects Arena.ai's Bash tool to the folder you choose. The conversation stays on Arena.ai; the desktop app handles local requests and puts permission decisions in your hands.

THE TOOLBOX

Small, explicit actions.

The bridge accepts five named actions—not a general-purpose HTTP proxy. Each request has a unique ID, a declared action, and validated arguments.

▤

READ

List and inspect

List folders, read text files, and search matching lines inside the selected workspace. Binary content is blocked, text reads over 256 KB are refused, and search skips candidate files over 512 KB.

✎

WRITE

Propose file changes

Ask mode prepares a diff on the desktop. Approvals are tied to the exact reviewed file state, so a changed file needs a fresh review.

$_

COMMAND

Run a shell command

Ask mode shows the exact command before it runs. Commands use your OS account and are not sandboxed.

⌂

SCOPE

Choose one workspace

File tools reject absolute paths, parent traversal, symlink traversal, protected directories, and known credential filenames.

◷

REVIEW

Approval queue

Pending writes and commands appear in Arena Local with a diff or exact command. You can approve once, allow the exact action for the session, or deny.

⇄

CONNECT

Temporary HTTPS link

The local API listens on loopback. ngrok forwards the authenticated API; the desktop UI itself is not served through the public tunnel.

THREE PERMISSION MODES

Choose the gate.

Ask is the default. Modes apply on this computer; the copied prompt also tells the agent to respect the live mode.

DEFAULT

Ask before changes

Reads run automatically. File writes and shell commands wait in the local approval queue until you decide.

RESTRICTIVE

Read only

File reads remain available. Writes and shell commands are denied, not silently rerouted.

VERY DANGEROUS

No approval

Writes and commands execute immediately. This is not a sandbox or a shortcut around OS permissions; data loss is possible.

No-approval mode requires two native confirmations, remains temporary, and resets when you stop the link, rotate the key, change workspaces, or close the app. Read the full safety model →
