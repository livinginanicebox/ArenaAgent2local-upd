THE GOOD STUFF

A little bridge.
A lot more control.

Arena Local keeps the conversation where it belongs—on Arena.ai—and handles approved tool requests on your computer.

▰

Workspace by default

File tools stay in your chosen folder. A separate, two-warning EXTREMELY DANGEROUS mode can remove that boundary; reads can expose private files.

✎

Review edits locally

Ask mode shows file diffs and exact shell commands in the desktop approval queue before they run.

02 / REVIEW
⇄

A narrow remote link

An authenticated task API is forwarded through ngrok HTTPS. The desktop UI itself is never served publicly.

PLEASE READ BEFORE CONNECTING

Shell access is powerful.

Commands run as your normal operating-system user and can reach outside the selected folder. Ask is the default. Read only blocks writes and commands. No approval — VERY DANGEROUS skips per-action prompts and can cause data loss; enable it only if you understand the consequences.
