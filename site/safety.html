THE IMPORTANT PART

Your desktop is in control.
Know the boundaries.

Arena Local makes remote tool requests visible and permissioned. It is not an operating-system sandbox, and anything you ask Arena to read is sent back to the Arena.ai session.

DATA FLOW

What leaves this computer?

Only request the files and actions that are relevant to the user's task. Do not assume that workspace contents stay local just because the app does.

STAYS LOCAL

Desktop interface

The Electron window and workspace browser are opened locally. The UI is not served through the ngrok tunnel.

ENCRYPTED LINK

Requested file data

Text requested with read or search tools travels over the temporary ngrok HTTPS connection and is returned to Arena.ai.

CAPABILITY

Pairing key

The copied prompt contains a short-lived bearer key. Anyone who obtains it may call the exposed API until the link stops or the key rotates.

SEPARATE SECRET

ngrok authtoken

The tunnel credential is stored on this computer when possible and is not included in the Arena prompt. Arena does not need it.

LOCAL PERMISSION CONTROLS

Three modes. No hidden middle.

Changing modes cancels pending changes and clears exact-action session approvals. The no-approval mode has two native confirmation dialogs.

DEFAULT / RECOMMENDED

Ask before changes

Reads run automatically. Writes show a proposed diff; shell requests show the exact command. You approve once, allow the exact action for the session, or deny.

READ-ONLY

Inspect, don't mutate

File writes and shell commands are denied. The agent must not retry by using another route or ask to weaken the control.

VERY DANGEROUS

No approval

Remote writes and commands run immediately without a per-action prompt. With full-computer access, a separate local-only sequence shows the exact warning, waits 30 seconds, requires slide-to-unlock and a final native confirmation, then rotates the key. This mode can cause data loss and resets when the connection stops, the key rotates, the workspace changes, or the app closes.

‼

EXTREMELY DANGEROUS · FULL COMPUTER ACCESS

The workspace boundary is removed.

This separate scope mode is off by default and requires two native confirmations while the tunnel is stopped. It lets Arena list, read, search, and propose writes anywhere your signed-in OS account can access—including hidden folders and credential files. Requested file contents are sent to Arena.ai; reads do not get a per-file approval. Ask mode still requires local write approval and Read only blocks writes. Combining full-computer access with No-Ask requires a new, local-only unlock: the exact warning appears, Continue stays locked for 30 seconds, then a slide-to-unlock and final native confirmation are required. The key rotates when the combination is enabled; a further native warning appears before the link starts. The mode is never saved and resets when the connection stops, the key rotates, the workspace changes, a connection attempt fails, or the app closes. The remote API cannot change modes or perform the unlock. It does not grant admin/root rights or sandbox OS access.

!

NO APPROVAL — VERY DANGEROUS

Shell commands can reach beyond the selected folder.

File-tool path checks do not constrain shell commands. An approved or auto-approved command runs as your signed-in OS user, can access files that account can reach, and may change or delete data. Approval is a pause for your decision—not a sandbox.

FILE-TOOL PROTECTIONS

Useful guardrails, not magic.

The checks below reduce accidental exposure through file tools. They do not protect against an unsafe shell command or a compromised operating system.

BLOCKED BY FILE TOOLS

Paths and sensitive names

  • In default workspace mode, absolute paths, parent traversal, and symlink traversal are blocked.
  • Protected directories such as .git, .ssh, .aws, and dependency/build folders are hidden from normal file actions.
  • Common credential filenames such as .env*, .npmrc, .netrc, private-key extensions, and credential files are protected by default.
  • Binary files; reads and writes over 256 KB; and search candidates over 512 KB are skipped or rejected.

EXTREMELY DANGEROUS full-computer access disables the workspace, protected-directory, and credential-name boundaries. The file-size and text-only limits still apply.

LIMITS TO REMEMBER

What the guardrails don't do

  • They do not sandbox terminal commands or restrict their OS permissions.
  • They do not stop Arena from receiving content you explicitly ask it to read.
  • They do not keep a copied bearer key secret after it has been shared.
  • They do not undo an action that you already approved and that is running.

Use a workspace you control, keep the prompt private, and inspect every command before approving it.

QUICK CHECKLIST

Before you click Connect.

  1. Choose only the folder needed for the task; leave full-computer access off unless the task requires it.
  2. Use Ask mode unless you have a specific, informed reason not to.
  3. Keep the Arena setup prompt and pairing key private.
  4. Read the exact command and review the complete diff before approving.
  5. Stop the link or rotate the key when finished.

PROTOTYPE NOTICE

Use the controls. Keep a backup.

Arena Local is an early prototype—not a security boundary for untrusted users or a replacement for OS-level isolation.
