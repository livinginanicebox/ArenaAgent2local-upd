BEFORE INSTALLING

Verify the release.

Only run the installer if it came from this project's official GitHub Releases page and matches the checksum published alongside it.

WINDOWS X64 / NSIS

Unsigned prototype build

The installer is not code-signed. Windows may show an unrecognized-publisher SmartScreen warning. That warning is expected for this build, but it is not proof that any file is safe—verify the source and checksum first.

SHA-256 SIDECAR

Compare before opening

Published releases include Arena-Local-Setup.exe.sha256. Download the checksum file from the same release and compare it with a locally calculated SHA-256 digest of the installer.

A matching hash helps detect accidental changes in transit; it does not replace trusting the release source.

POWERSHELL / SHA-256(Get-FileHash .\Arena-Local-Setup.exe -Algorithm SHA256).HashCompare this output to the hash in the downloaded .sha256 file.
